# VisionFlow Automator v0.5.0 更新内容

## 新增功能与效果

- **识别能力**：支持 OCR 文字识别；新增步骤级重试、执行前体检、全局兜底处理，识别失败时更可控。
- **识别调试**：可查看执行步骤历史，点击步骤号码回看当时的识别画面。
- **蓝图编辑**：支持进入分组子图、把选中步骤/组保存为片段并复用、框选与多选整块拖动。
- **界面体验**：预设管理收进下拉菜单、保存常驻并支持 `Ctrl+S`；新增底部状态栏（运行状态/进度/预检）、撤销重做、`Ctrl+C`/`Ctrl+V` 复制粘贴、日志上限与清空；编辑器显示「未应用/已保存」。
- **执行安全**：开始执行前校验目标窗口，窗口不存在时明确提示并阻止启动。
- **更新检查**：自动检查新版本，代理地址可在程序「设置」中填写。
- **打包分发**：一键打包；打包版为空白纯净包，不带内置/保存的预设、图片、片段与设置。

## 修复

- 修复打包版启动报 `PermissionError`（图标资源被错误打成目录）。
- 修复组行复选框不显示、只在鼠标悬浮时出现，以及组行左侧白边。
- 修复蓝图折叠组连线断开、组框不收缩、组/选中连线的框选与多组拖动异常。
- 修复片段连续插入后分组丢失、组与步骤插入位置错位。
- 修复多选步骤拖动只移动一条、空预设无法右键新建步骤等问题。
