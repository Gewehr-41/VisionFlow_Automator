# VisionFlow Automator v0.5.1 更新内容

## 新功能

- **一键自动更新**：打包版检测到新版本、且 Release 里上传了打包 zip 时，可直接选择「自动更新」——
  后台下载并校验更新包，程序退出后自动替换并重新启动；用户数据保留，旧程序自动备份，失败会回滚。
  没有 zip 资产或源码运行时，仍打开发布页手动下载。
- **自定义图标**：把你的 `app.ico` 放到工程根目录后重新打包，exe、窗口标题栏和任务栏都会使用你的图标。
- **打包版为空白纯净包**：首次启动不带内置预设、示例步骤、模板图片、片段与设置，用户拿到的是干净软件。

## 修复

- 修复打包版启动报 `PermissionError`（图标资源被错误打成目录）。
- 打包与 zip 会排除自动更新产生的 `_backup_update_*` 旧程序备份。

## 升级方式

- 已安装 v0.5.0 打包版的用户：打开程序点「检查更新」，选择「自动更新」即可。
- 也可以下载本 Release 里的 zip，解压后覆盖程序目录（保留你自己的 `saved_*.json` 数据）。
