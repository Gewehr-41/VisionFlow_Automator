# VisionFlow Automator v0.5.1 更新内容

## 新功能

- **一键自动更新**：打包版发现新版本且 Release 里有打包 zip 时，可选「自动更新」——后台下载并校验更新包，
  程序退出后自动替换并重新启动；用户数据保留，旧程序自动备份，失败会回滚。源码运行或无 zip 时仍打开发布页。
- **下载进度**：下载更新包时底部进度条显示下载进度（百分比 + 已下载/总 MB），完成后恢复步骤进度。
- **自定义图标**：工程根目录放 `app.ico` 后重新打包，exe、窗口标题栏和任务栏都会使用你的图标。
- **打包版为空白纯净包**：首次启动不带内置预设、示例步骤、模板图片、片段与设置。

## 修复

- 修复自动更新卡在 `find "<PID>"` 终端：更新助手改为后台隐藏运行，等待旧程序退出（120 秒超时）后替换并重启。
- 更新退出增加强制兜底；更新助手使用 UTF-8 BOM，中文安装目录不会乱码。
- 修复打包版启动报 `PermissionError`（图标资源被错误打成目录）。
- 打包与 zip 排除自动更新产生的 `_backup_update_*` 旧程序备份。

## 升级方式

- 已安装旧版本的打包版：打开程序点「检查更新」→「自动更新」（需要 Release 里上传打包 zip）；
  也可以下载本 Release 的 zip，解压后覆盖程序目录（保留自己的 `saved_*.json` 数据）。
