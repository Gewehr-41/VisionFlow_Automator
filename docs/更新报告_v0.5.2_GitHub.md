# VisionFlow Automator v0.5.2 更新内容

## 识别
- 识别算法增强：模板缓存、上次命中点持久化、alpha 掩膜 + 颜色校验、确定性选择/多帧确认、
  OCR 预处理/模糊匹配、ORB 特征兜底（默认关闭）。
- 分辨率归一化 + 粗到细搜索；尺度早停与粗搜 miss 跳过，显著降低识别耗时。
- OCR 提速：全屏缩到 1280px、单行 ROI 跳过检测、同画面结果缓存。

## 体验
- 脚本开始执行自动最小化主窗口，结束/停止/异常后恢复。
- 状态栏显示「本次耗时」，执行中每 200ms 刷新，结束后冻结。
- 绑定图片对话框点「保存」立即写入并持久化；点「叉」保留改动并显示「未应用」。

## 修复
- 修复自动最小化后「识别到但不操作」（前景模式点击坐标重复加窗口偏移）。
- 修复有手动框选时识别耗时回退约 10s（框选优先，不再叠加命中点窗口）。
- 更新包下载文件自动清理；更新助手隐藏运行、超时回滚、中文路径 BOM 等沿用 v0.5.1。

## 升级方式
- 自动更新：需要在本 Release 上传打包 zip（文件名含 `VisionFlow`）。
- 手动更新：下载 zip 解压覆盖程序目录，保留 `saved_*.json` 用户数据。
