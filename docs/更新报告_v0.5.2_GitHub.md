# VisionFlow Automator v0.5.2 更新内容

## 修复

- **修复自动更新卡在终端**：下载更新后不再弹出 `find "<PID>"` 的 cmd 窗口；更新助手改为**后台隐藏运行**，
  等待旧程序退出（120 秒超时）后自动替换并重新启动，替换失败会回滚。
- 更新退出增加强制兜底，避免主程序没退干净时更新助手一直等待。
- 更新助手脚本使用 UTF-8 BOM，**中文安装目录**（如 `VisionFlow_Automator_打包版`）不再乱码导致替换失败。

## 升级方式

- v0.5.1 的自动更新助手有卡住问题，**建议手动下载本 Release 的 zip 覆盖一次**（保留自己的 `saved_*.json` 数据）；
  换到 0.5.2 后，后续版本即可正常使用一键自动更新。
