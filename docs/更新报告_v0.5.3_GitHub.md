# VisionFlow Automator v0.5.3 更新内容

## 新功能
- **文件级增量更新**：以后小版本更新只需下载变化文件（delta zip），不再每次下载完整安装包；
  没有本地清单或版本不匹配时自动退回完整包。
- **按键步骤支持按下次数 + 每次间隔**：例如按 3 次、每次间隔 0.5 秒。
- **步骤类型名称改为中文**：普通步骤、循环、按键、拖拽、延迟、条件、选择、事件等。

## 修复
- 修复类型专用字段修改后状态胶囊仍显示「已保存」（key_press / keyboard_move / drag / delay /
  condition / switch / loop / event）。

## 升级方式
- **v0.5.2 用户请使用完整包升级一次**（v0.5.2 安装目录还没有 `update_manifest.json`，无法使用增量包）；
  升级到 v0.5.3 后，后续版本即可走增量更新。
- Release 中完整包与增量包：
  - 完整包文件名保留 `VisionFlow`；
  - 增量包文件名以 `delta` 开头。
- 保留自己的 `saved_*.json` 用户数据。
