脚本编辑器蓝图化更新目标
========================

一、基础连接与数据可靠性（优先处理）
[x] 修复默认顺序连接无法真正断开的问题
[x] 区分“未设置连接”和“明确断开连接”
[x] 保存蓝图节点位置、缩放比例和画布布局
[x] 删除节点时清理所有指向该节点的普通连接和迂回连接
[x] 重启程序后恢复蓝图布局
[x] 校验连接目标不存在、连接自身和连接循环等异常情况

二、蓝图核心执行能力
[x] 让执行器以蓝图连接关系作为主要执行路径
[ ] 支持一个节点连接多个输出节点
[x] 增加条件分支节点（基于模板识别）
[x] 增加 Switch/选择节点（静态值匹配）
[x] 增加循环节点和跳出循环节点（固定次数）
[x] 增加独立延迟节点
[x] 增加事件触发节点（等待模板出现）
[x] 统一条件、选择和循环节点的分支出口解析
[x] 明确禁止并行连接，当前采用单路径执行
[x] 执行时高亮当前节点
[x] 执行时高亮实际经过的主线连线

三、迂回与条件系统
[x] 识别成功、未识别、超时分别使用独立输出端口
[ ] 支持置信度条件
[x] 支持模板出现、模板消失和画面变化条件
[x] 支持等待超时结果条件
[ ] 支持点击失败结果条件
[x] 增加 AND、OR、NOT 条件组合节点
[x] 支持多个分支出口（条件、迂回和 Switch）
[ ] 迂回分支连接和普通连接使用统一的节点接口

四、数据引脚与变量
[ ] 增加布尔、数字、字符串等变量节点
[ ] 传递模板识别结果、坐标和置信度
[ ] 增加设置变量、读取变量和比较变量节点
[ ] 支持步骤之间传递执行结果
[ ] 增加流程级变量和预设级变量

五、编辑体验
[x] 支持 Ctrl+Z 撤销和 Ctrl+Y 重做
[x] 支持 Ctrl+C、Ctrl+V 快捷复制粘贴
[x] 复制粘贴时保留内部普通连接和迂回连接
[x] 增加节点注释和现有流程分组
[x] 增加节点对齐、自动排列和网格吸附
[x] 支持节点折叠、重命名和颜色分类
[x] 支持连接线重新路由和弯曲调整
[x] 框选节点后同步选中内部连接
[ ] 支持节点与连线作为统一对象复制、删除和移动

六、调试与验证
[x] 增加单步执行
[x] 增加暂停、继续和从当前节点开始执行
[x] 显示当前节点、已执行节点和失败节点状态
[x] 显示实际命中的模板、坐标和置信度
[x] 增加蓝图连接完整性检查
[x] 增加流程循环检测和不可达节点提示
[x] 为节点连接、分支和布局增加自动化测试（专项验证）

七、架构优化
[x] 抽象统一的节点接口：execute、validate、inputs、outputs
[x] 将任务字典迁移为可序列化节点和连接模型（保留旧 JSON 兼容导入）
[x] 将普通步骤、特殊步骤、条件步骤统一为可扩展节点类型（适配层）
[x] 将蓝图布局数据与任务执行数据分离保存
[x] 保持旧版任务 JSON 格式兼容迁移

当前建议开发顺序
1. 默认连接断开与布局持久化
2. 统一蓝图连接执行路径
3. 条件分支和多出口
4. 变量与数据引脚
5. 撤销重做、自动排列和调试模式
